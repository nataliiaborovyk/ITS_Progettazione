# ITS_Progettazione – Esercizi di Progettazione e UML (ITS ICT Academy)

Questo repository contiene esercizi sviluppati durante il corso di **Progettazione di Sistemi Informativi** presso ITS ICT Academy.

L'obiettivo principale del repository è documentare l'apprendimento delle tecniche di modellazione e progettazione dei sistemi tramite UML.

I contenuti includono:

- diagrammi UML
- ristrutturazione di modelli concettuali
- esercizi di progettazione di sistemi e loro implementazione in python
- specifiche derivate da modelli UML

Il repository mostra il passaggio da esercizi di modellazione più semplici a problemi di progettazione più complessi.

Questo repository fa parte del mio percorso di apprendimento durante il programma Data Analyst presso ITS ICT Academy.
